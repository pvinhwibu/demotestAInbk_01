Kết nối AI

Kết nối nhà cung cấp có API tương thích OpenAI để nhận phân tích bằng mô hình ngôn ngữ. Nếu bỏ trống API key, TRACE AI vẫn chạy bằng chế độ demo ngoại tuyến.

Ví dụ: https://api.openai.com/v1 (không thêm /chat/completions)
Quan trọng về bảo mật: Đây là website chạy trực tiếp trong trình duyệt. Khi nhập API key tại đây, khóa sẽ được trình duyệt gửi đến nhà cung cấp API và người có quyền truy cập thiết bị hoặc công cụ phát triển có thể xem được. Không dùng khóa bí mật của tổ chức/trường học. Khi triển khai cho nhiều người, hãy gọi AI qua máy chủ riêng và giữ khóa ở phía máy chủ. API cũng có thể phát sinh chi phí và yêu cầu giới hạn sử dụng.
